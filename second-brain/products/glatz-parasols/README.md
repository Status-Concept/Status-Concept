# Glatz Parasols — one file per model

21 models, organised by Glatz's own categories. Images live in
[`../glatz-images/`](../glatz-images/README.md). Range overview, fabric system
and selling angles: [`../glatz-shade.md`](../glatz-shade.md).

tested, 70 fabric colours in classes 5/4/2, >98% UV protection (SPF 50,
SQTS-certified), PFAS-free textiles, original bases/covers/spare parts.
