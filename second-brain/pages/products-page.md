# Products Page

**Route:** `/products`
**File:** `src/pages/status-concept-products.jsx`

## Features
- Browse all 139+ products
- Filter by category (12 categories)
- Kitchen sub-filter by collection (Black Stainless Steel, Carbon Line Teak, Teak)
- Search
- Grid / List view toggle
- Sort options: Featured, Price (asc/desc)
- Mobile-responsive filter drawer

## Product Detail
**Route:** `/product/:id`
**File:** `src/pages/status-concept-product-detail.jsx`

### Detail Page Sections
- Multi-image gallery with lightbox
- Tabs:
  - **Specs** — SKU, type, material, etc.
  - **Dimensions** — Width, depth, height, seat height table
  - **Materials** — Fabric/finish details
  - **Colors** — Swatches with hex codes
- Related products carousel
- Favorite (heart) button
